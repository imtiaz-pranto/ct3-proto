Include customer details in scripts
Shares the shopper's ID, email and name with your scripts on a verified order, and they wait for consent when Respect cookie choices is on. Only administrators can edit scripts.

Customer placeholders fill in only while this is on, only for a verified order on the thank-you page, and, with Respect cookie choices on, only after the shopper allows marketing cookies. Everywhere else they stay empty, so personal data never lands in a page by accident.

Adding a custom script

  1. Copy the tag from the platform's setup page. Most give you a base tag and a purchase tag.
  2. Paste the base tag into Every page, in the header.
  3. Paste the purchase tag into Thank-you page and swap the fixed values for placeholders like {order_total}.
