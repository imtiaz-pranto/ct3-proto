# Logo sources

Fetched 2026-10-23 by Claude Code for task 3.1 (prototype). All files are 1x SVG; no PNG fallback was needed because every fetched mark is vector. Used only to identify the platform the store connects to (referential use), at 24 px in lists and 40 px in detail headers, original colours on white. The "Not set up" state shows them in greyscale via CSS (`.logo.is-off`), not as separate files.
