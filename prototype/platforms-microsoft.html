Where to find your UET tag ID

  1. In Microsoft Advertising, open Tools, then UET tag.
  2. Find the tag for this store. The ID is the number in the Tag ID column.
  3. Paste it into the UET tag ID field. We check the format as you type.

Pause tracking on Microsoft Advertising?

Nothing is sent to Microsoft until you resume. Your UET tag ID stays saved. Your ads keep running, but Microsoft won't see new sales from this store while it's paused.
