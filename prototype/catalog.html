Connect the feed in Commerce Manager

  1. Open Commerce Manager and choose Create catalog.
  2. Pick E-commerce as the catalog type.
  3. Name it, for example after your store.
  4. In the new catalog, open Data sources and choose Add items.
  5. Choose Data feed, then Scheduled feed.
  6. Paste the feed URL from this page.
  7. Set a daily schedule and choose Start upload.
