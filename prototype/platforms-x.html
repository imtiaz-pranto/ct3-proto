Hook reference

Where to find the event ID

  1. In X Ads Manager, open Tools, then Events Manager.
  2. Choose Add event, pick Purchase and the Pixel install method.
  3. Copy the ID that starts with tw- and paste it into the Purchase event ID field. Repeat for Add to cart, Start checkout or Registration if you want those too.
